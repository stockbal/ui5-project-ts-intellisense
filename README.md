# Enabling SAPUI5/OpenUI5 type intellisense during development

This repository demonstrates how one can enable content assist (auto completion) and/or type checking in a UI5 application.

There are 3 possible approaches depending on your style of developing, starting with the classic approach of writing UI5 modules with `sap.ui.define` until finally arriving at an application that is developed completely in TypeScript.

## Available scenarios

- [Using classic approach with `sap.ui.define`](https://github.com/stockbal/ui5-project-ts-intellisense/tree/sap-ui-define)
- [Using ES6 modules syntax](https://github.com/stockbal/ui5-project-ts-intellisense/tree/es6-javascript)
- [Using TypeScript](https://github.com/stockbal/ui5-project-ts-intellisense/tree/typescript)
